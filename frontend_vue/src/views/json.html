🖥️ Vue Component — نقطة البداية

    ⏱️
    Timeline الكامل

    الترتيب الزمني لكل حدث من لحظة إرسال الـ Request

    Vue Layer
    1. Event يحصل (click, submit, mounted…)
    الـ Component بيشغّل method أو composable — بيبدأ فيها الـ loading state
    Vue Layer
    2. بناء الـ Request Object
    URL، Method، Headers (Content-Type، Authorization)، Body (لو POST/PUT)
    Network Layer
    3. إرسال الـ HTTP Request
    axios/fetch بتبعت الـ request — بتضيف الـ headers التلقائية، بتعمل serialize للـ body لـ JSON
    Django Layer
    4. WSGI/ASGI يستقبل الـ Request
    Django بيعمل parse للـ raw HTTP لـ HttpRequest object
    Django Middleware
    5. Middleware Stack
    بيعدي على: SecurityMiddleware ← SessionMiddleware ← CORS ← CsrfViewMiddleware ← AuthMiddleware
    DRF Layer
    6. URL Routing
    urlpatterns بيطابق الـ URL pattern — بيحدد الـ View المسؤول
    DRF Layer
    7. Authentication & Permissions
    بيتحقق من الـ token/session — بيشيك permission_classes (IsAuthenticated, IsAdminUser…)
    DRF Serializer
    8. Serialization / Deserialization
    Request data → Python dict → Validate → Model instance. أو Model → Python dict → JSON
    Database
    9. ORM Query
    Django ORM بيحوّل الكود لـ SQL — SELECT/INSERT/UPDATE/DELETE
    Response
    10. بناء وإرسال الـ Response
    Status Code + JSON Body + Headers (Content-Type, CORS headers…)
    Vue Layer
    11. معالجة الـ Response
    .then() / await → تحديث الـ reactive state → إيقاف الـ loading → عرض البيانات أو الخطأ
    📡
    HTTP Methods

    كل method وامتى تستخدمها وإيه اللي بتعمله على الـ API

    Method الغرض Body في الـ Request؟ Safe؟ Idempotent؟ DRF Action Status الناجح
    GET جلب بيانات ✗ ✓ ✓ list() / retrieve() 200
    POST إنشاء جديد ✓ ✗ ✗ create() 201
    PUT تحديث كامل ✓ ✗ ✓ update() 200
    PATCH تحديث جزئي ✓ ✗ ✓ partial_update() 200
    DELETE حذف ✗ ✗ ✓ destroy() 204
    ⚠️ PUT vs PATCH: PUT لازم يبعت كل الفيلدز حتى اللي مش اتغيرت — لو بعت بيانات ناقصة الـ Serializer هيرفض أو يمسح قيم. PATCH بيبعت بس اللي اتغير.

    🚦
    HTTP Status Codes

    كل كود وإيه معناه وإيه موقفك منه في Vue

    2xx — نجاح ✅
    200
    OK
    الـ GET أو PUT أو PATCH نجح — في بيانات في الـ body
    201
    Created
    الـ POST نجح وأنشأ resource جديد — الـ body بيرجع الـ object الجديد
    204
    No Content
    الـ DELETE نجح — الـ body فاضي، ما فيش response.data
    206
    Partial Content
    بيانات جزئية — غالباً في pagination أو streaming
    3xx — Redirect 🔀
    301
    Moved Permanently
    الـ URL اتغير — axios بيـ follow تلقائياً
    304
    Not Modified
    الـ Cache لسه valid — ما فيش بيانات جديدة
    4xx — خطأ من جهتك (Client) ⚠️
    400
    Bad Request
    البيانات اللي بعتها غلط — validation error من الـ Serializer. شوف response.data.errors
    401
    Unauthorized
    ما فيش token أو الـ token منتهي — وجّه اليوزر لصفحة Login
    403
    Forbidden
    في token بس مش عنده permission — اليوزر موجود بس مش مصرحله
    404
    Not Found
    الـ resource مش موجود — غالباً الـ ID غلط أو اتحذف
    405
    Method Not Allowed
    الـ View مش بيقبل الـ method دي — راجع allowed_methods في DRF
    409
    Conflict
    تعارض — زي unique constraint مكرر (email موجود مثلاً)
    422
    Unprocessable Entity
    البيانات مفهومة بس فيها خطأ منطقي في الـ Validation
    429
    Too Many Requests
    تجاوزت الـ Rate Limit — انتظر أو اعرض رسالة للمستخدم
    5xx — خطأ من جهة السيرفر 🔥
    500
    Internal Server Error
    Django وقع في Exception — راجع الـ Django logs فوراً
    502
    Bad Gateway
    الـ Nginx/Proxy مش قادر يوصل Django — مشكلة في الـ deployment
    503
    Service Unavailable
    السيرفر مشغول أو down — اعرض رسالة "اتصل بعدين"

    شكل البيانات

    إيه بيتبعت وإيه بيرجع — Request Body وResponse Body

    📤 Request — إيه اللي بتبعت
    الـ Content-Type في الـ Header بيحدد شكل الـ Body:
    application/json multipart/form-data application/x-www-form-urlencoded
    📥 Response — إيه اللي بيرجع
    DRF دايماً بيرجع JSON (JSONRenderer). الـ body موجود في:
    response.data // axios await res.json() // fetch
    📤 أشكال الـ Request Body
    JSON Body (POST/PUT/PATCH)
    // Vue - axios const data = { name: "Product A", price: 99.99, category: 3 } axios.post('/api/products/', data) // axios بيضيف Content-Type: application/json تلقائياً
    FormData (لو فيه files)
    // Vue - لو فيه upload صورة const form = new FormData() form.append('name', 'Product A') form.append('image', file) // File object axios.post('/api/products/', form, { headers: { 'Content-Type': 'multipart/form-data' } })
    Query Params (GET فلترة)
    // Vue - GET مع فلاتر axios.get('/api/products/', { params: { category: 3, page: 1, search: 'laptop' } }) // بيبقى: /api/products/?category=3&page=1&search=laptop
    Auth Header
    // في كل request محتاج auth axios.get('/api/profile/', { headers: { Authorization: `Token ${token}` // أو: Bearer ${token} لو JWT } })
    📥 أشكال الـ Response Body من DRF
    List Response (GET /api/products/)
    // بدون pagination [ { "id": 1, "name": "Laptop", "price": 999 }, { "id": 2, "name": "Phone", "price": 599 } ] // مع PageNumberPagination { "count": 47, "next": "http://.../api/products/?page=2", "previous": null, "results": [ ... ] }
    Single Object (GET /api/products/1/)
    { "id": 1, "name": "Laptop Pro", "price": "999.99", "category": { // nested object "id": 2, "name": "Electronics" }, "tags": ["sale", "new"], // array "created_at": "2024-01-15T10:30:00Z" }
    Validation Error (400)
    { "name": ["This field is required."], "price": ["A valid number is required."], "email": ["Enter a valid email address."] } // في Vue const errors = error.response.data // errors.name[0] → "This field is required."
    Auth Error (401)
    { "detail": "Authentication credentials were not provided." } // أو { "detail": "Invalid token." } // في Vue error.response.data.detail
    🧠 قاعدة مهمة: الـ Serializer في DRF هو اللي بيحدد شكل الـ Response. لو عايز تضيف فيلد، غيّره في الـ Serializer مش في الـ Model مباشرة. وأي حقل في الـ Model مش في الـ Serializer — مش هيظهر في الـ Response.

    Vue 3 — Composable للـ API
    // composables/useApi.js import { ref } from 'vue' import axios from 'axios' export function useApi() { const data = ref(null) const loading = ref(false) const error = ref(null) const execute = async (config) => { loading.value = true error.value = null try { const res = await axios(config) data.value = res.data return res.data } catch (e) { error.value = e.response?.data || e.message throw e } finally { loading.value = false } } return { data, loading, error, execute } }

    // services/api.js import axios from 'axios' const api = axios.create({ baseURL: import.meta.env.VITE_API_URL, headers: { 'Content-Type': 'application/json' } }) // Interceptor: ضيف token تلقائياً api.interceptors.request.use(config => { const token = localStorage.getItem('token') if (token) config.headers.Authorization = `Token ${token}` return config }) // Interceptor: handle 401 globally api.interceptors.response.use( res => res, err => { if (err.response?.status === 401) router.push('/login') return Promise.reject(err) } ) export default api
    Django DRF — ViewSet كامل
    # views.py from rest_framework import viewsets, permissions from rest_framework.decorators import action from rest_framework.response import Response from .models import Product from .serializers import ProductSerializer class ProductViewSet(viewsets.ModelViewSet): queryset = Product.objects.all() serializer_class = ProductSerializer permission_classes = [permissions.IsAuthenticated] def get_queryset(self): """فلترة حسب اليوزر الحالي""" return super().get_queryset().filter( owner=self.request.user ) # Custom action: POST /api/products/{id}/publish/ @action(detail=True, methods=['post']) def publish(self, request, pk=None): product = self.get_object() product.is_published = True product.save() return Response({'status': 'published'})
    Django DRF — Serializer مع Validation
    # serializers.py from rest_framework import serializers from .models import Product class ProductSerializer(serializers.ModelSerializer): # فيلد computed (read only) discount_price = serializers.SerializerMethodField() class Meta: model = Product fields = ['id','name','price','discount_price'] read_only_fields = ['id'] def get_discount_price(self, obj): return obj.price * 0.9 def validate_price(self, value): """Field-level validation""" if value < 0: raise serializers.ValidationError( "السعر لازم يكون موجب" ) return value def validate(self, data): """Object-level validation""" if data['end_date'] < data['start_date']: raise serializers.ValidationError( "التاريخ غلط" ) return data
    🔄 الـ Error Handling الكامل في Vue
    async function submitForm() { loading.value = true fieldErrors.value = {} // reset validation errors try { const res = await api.post('/api/products/', formData.value) // ✅ نجح — 201 products.value.push(res.data) showToast('تم الإضافة بنجاح', 'success') } catch (err) { const status = err.response?.status const body = err.response?.data if (status === 400) { // Validation errors من الـ Serializer fieldErrors.value = body // { name: ['...'], price: ['...'] } } else if (status === 401) { logout() router.push('/login') } else if (status === 403) { showToast('مش عندك صلاحية', 'error') } else if (status === 404) { showToast('العنصر مش موجود', 'error') } else if (status >= 500) { showToast('خطأ في السيرفر، حاول تاني', 'error') } else if (!err.response) { // Network error — ما وصلناش للسيرفر أصلاً showToast('تحقق من الاتصال بالإنترنت', 'warning') } } finally { loading.value = false } }

    🔍
    خريطة تشخيص سريعة
    🔴 CORS Error
    المشكلة دايماً في Django.
    تأكد من: django-cors-headers مثبت، CORS_ALLOWED_ORIGINS يحتوي على URL الـ Vue، وcorsheaders.middleware أول حاجة في MIDDLEWARE.
    🟡 Network Error (no response)
    Django مش شغال أصلاً أو الـ URL غلط.
    تأكد: الـ server شغال، الـ baseURL صح، مفيش typo في الـ endpoint.
    🔵 البيانات وصلت بس فاضية
    راجع الـ Serializer fields، تأكد الـ queryset مش empty، وشوف لو الـ filter بيفلتر غلط.
    🟣 400 بدون رسالة واضحة
    افتح Browser DevTools → Network → شوف الـ Response body. فيه الـ validation errors بالتفصيل.
    🔴 500 Internal Server Error
    افتح Django terminal — هتلاقي الـ Traceback الكامل هناك. أو فعّل DEBUG=True مؤقتاً.
    🟢 أدوات لازم تعرفها
    Browser DevTools (Network tab)، DRF Browsable API (/api/products/)، print(request.data) في Django، Vue DevTools.
